Import transactions

How to build the file to add transactions to SPNT.

In the app, Settings › Data › Import transactions adds transactions from a CSV or JSON without deleting anything you already have. Before adding, you see what goes in, what looks repeated and what has errors.

The file

A UTF-8 CSV with one row per transaction. The first row is the header. Commas or semicolons both work, and column order doesn’t matter. A JSON array with the same keys works too.

Columns

ColumnRequiredWhat it holds
dateYesThe date as YYYY-MM-DD, for example 2026-11-20.
amountYesA number with a decimal point, no currency symbol or thousands separator. Negative if money went out, positive if it came in.
kindNoEmpty: worked out from the sign and whether it’s an account or a card. Otherwise: expense, income, transfer, cardCharge, cardCredit or cardPayment.
accountYesThe name of an account or card, as it is in the app. Case and accents don’t matter.
destinationFor transfer and cardPaymentThe destination account, or the card you’re paying.
category, subcategoryNoAs they are in the app. Empty: uncategorized.
noteNoThe description, for example the merchant.
tagsNoTags separated by |.
currencyNoA 3-letter code such as EUR. Empty: your main currency.
statementNoCards only: the statement’s closing date, if you want to pick it.
pendingNotrue if it’s still to be paid.
external_idNo, but recommendedA stable id from the source: the email’s id or the authorization number. With it, importing the same file again duplicates nothing.

With your assistant

If you already have an agent that reads your bank emails, or you use ChatGPT or Claude, ask it for the file:

  1. In the app, open Settings › Data › Import transactions and tap “Copy instructions for your assistant”. They include your accounts, cards and categories.
  2. Paste them into your assistant along with your emails, statements or whatever you have.
  3. Save the CSV it gives back and choose it in the app, or open it from Files or Mail with “Open with… › SPNT”.

Questions

Does it delete what I already have?

No. Import transactions only adds. And if something didn’t come out right, you can open each import to review and edit its transactions, or undo it entirely.

What if I import the same file twice?

Rows with the same external_id are skipped. Rows without one that look like something already there (same amount, same account, nearby dates) show up as possible duplicates and don’t go in unless you turn them on.

How do I undo an import?

On the same screen, under “Imports”, each one has “Undo”, which deletes the transactions it added.

What if an account or category doesn’t exist in the app?

The preview lets you pick one you have, create it or skip those rows. The app remembers your choice for next time.

Does it cost anything?

Importing is free. What you import follows your plan: more than 2 accounts or cards and other currencies are part of Premium.
