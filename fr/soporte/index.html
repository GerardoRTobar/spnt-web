Abonnement

Comment résilier mon abonnement ?

Les abonnements se gèrent depuis votre compte Apple. Sur votre iPhone, allez dans Réglages → votre nom → Abonnements → SPNT. Vous pouvez aussi ouvrir apps.apple.com/account/subscriptions.

J’ai changé d’iPhone et je ne vois pas Premium

Ouvrez l’écran des formules dans l’app et touchez « Restaurer les achats ». Utilisez le même compte Apple que pour le paiement.

Vos données

Comment transférer mes données sur un autre iPhone ?

Connectez-vous avec le même compte sur les deux appareils. Avec Premium, vos données se synchronisent toutes seules.

Comment exporter mes données ?

Depuis l’app, vous pouvez exporter vos transactions vers Excel ou CSV, ou créer un rapport PDF.

Comment supprimer mon compte ?

Dans l’app, allez dans Réglages, touchez votre profil en haut et choisissez « Supprimer le compte ». Votre compte et vos données dans le cloud sont supprimés. Plus de détails dans la politique de confidentialité.

SPNT se connecte-t-il à ma banque ?

Non. SPNT ne connaît que ce que vous saisissez. L’app ne demande ni identifiant ni mot de passe bancaire.
